# Create Fly: Deco

Industrial decoration for Create: metal bars, catwalks, cage lamps, shipping containers, sheet metal, coins, decals and eight colors.

> [!IMPORTANT]
> **This is an unofficial port.** It is not affiliated with or endorsed by
> Talrey. 
> Please report problems here.

## Compatibility

| Component | Version |
| --- | --- |
| Minecraft | `26.3` |
| Mod loader | Fabric Loader `0.20.1` or newer |
| Create Fly | `6.0.9-1` or newer |
| Fabric API | required |
| Java | `25` or newer |
| Environments | Client and server |

## Download

- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/create-fly-deco)
- [GitHub releases](https://github.com/chaevsfe/CreateDeco/releases)


## Building

```
git clone https://github.com/chaevsfe/CreateDeco
cd CreateDeco
./gradlew build
```

Requires JDK 25.
